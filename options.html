Quick Image Saver

Save settings

Save location

Note: Images are saved inside the browser's default downloads folder.

Filename conflict handling

If checked, the browser will generate a unique filename when a file already exists. If unchecked, the existing file will be overwritten.

Filter small images

The save icon appears only for images wider than the selected value.

Show download buttons

When disabled, the floating download buttons are hidden. Modifier+click saving still works.

Save with modifier key

The selected modifier+click combination saves the image directly when clicked.
